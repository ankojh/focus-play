# Original sample sources

`database-indexes.txt` is original teaching material written for this project. It covers general relational database concepts and names no product version. It is not a video transcript.

`index-process.vtt` is a short original timed teaching fixture. Its times are fixture timings supplied by the file. They do not refer to a real YouTube video. Use it to check timed import and reference display.

`teaching-quality.json` adds original technical, conceptual, practical and narrow-goal passages, hand-authored beginner/knowledgeable reference outlines, baseline weaknesses and illustrative authored before/after samples. These are offline test/design fixtures, not live model outputs or a measured improvement baseline. See `docs/teaching-quality.md` for the evaluation rubric and remaining live checks.
